# System Sequence Diagrams (SSDs) – POS Retail Clothing Store

**UP Phase:** Elaboration Phase  
**Methodology:** Unified Process (Larman, *Applying UML and Patterns*)

A System Sequence Diagram (SSD) treats the entire system as a single black-box object (`:System`) and illustrates the input system events generated by actors and the system's corresponding return messages.

---

## SSD1: Login (UC1)

```mermaid
sequenceDiagram
    actor U as User (Cashier/Manager/Admin)
    participant S as :System

    U->>S: login(username, password)
    alt Valid Credentials
        S-->>U: authenticationSuccess(sessionToken, userRole, employeeName)
    else Invalid Credentials / Account Locked
        S-->>U: authenticationFailed(errorMessage)
    end
```

---

## SSD2: Process Sale (UC2)

```mermaid
sequenceDiagram
    actor C as Cashier
    participant S as :System

    C->>S: makeNewSale()
    S-->>C: saleInitiated(saleId)
    loop For Each Item
        C->>S: enterItem(sku, quantity)
        S-->>C: itemDetails(description, size, color, unitPrice, lineSubtotal, runningTotal)
    end
    opt Customer Attachment
        C->>S: attachCustomer(customerId)
        S-->>C: customerAttached(customerName)
    end
    C->>S: endSale()
    S-->>C: saleSummary(grandTotal, taxAmount)
    C->>S: makePayment(amountTendered, paymentMethod)
    S-->>C: paymentResult(changeDue, receiptData)
```

## SSD3: Manage Inventory – Restock Item (UC3)

```mermaid
sequenceDiagram
    actor M as Store Manager
    participant S as :System

    M->>S: startRestockSession()
    loop For Each Received Product Variant
        M->>S: enterRestockItem(sku, quantityReceived)
        S-->>M: variantInfo(productName, currentStock, projectedStock)
        M->>S: confirmRestock(sku, quantityReceived)
        S-->>M: restockConfirmed(updatedStockQuantity)
    end
    M->>S: closeRestockSession()
    S-->>M: restockSummaryReport()
```

## SSD4: Manage Employees – Onboard & Assign Role (UC4)

```mermaid
sequenceDiagram
    actor SA as Super Admin
    participant S as :System

    SA->>S: onboardEmployee(name, username, password, role)
    alt Valid Data & Unique Username
        S-->>SA: employeeCreated(employeeId, statusConfirmed)
    else Username Taken / Invalid Password
        S-->>SA: creationError(reason)
    end
    opt Role Reassignment
        SA->>S: updateEmployeeRole(employeeId, newRole)
        S-->>SA: roleUpdatedSuccess()
    end
```

## SSD5: Manage Products (UC5)

```mermaid
sequenceDiagram
    actor M as Store Manager / Admin
    participant S as :System

    M->>S: addProductVariant(styleCode, name, basePrice, sku, size, color, unitPrice, initialStock)
    alt Valid Variant & Unique SKU
        S-->>M: variantCreated(sku, status)
    else Duplicate SKU
        S-->>M: error(skuAlreadyExists)
    end
```

## SSD6: Register Customer (UC6)

```mermaid
sequenceDiagram
    actor C as Cashier / Manager
    participant S as :System

    C->>S: registerCustomer(name, phone, email)
    alt New Phone/Email
        S-->>C: customerRegistered(customerId, name)
    else Customer Exists
        S-->>C: existingCustomerFound(customerId, details)
    end
```
